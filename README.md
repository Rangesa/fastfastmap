# FastFastMap

Minecraft 1.21.11 向け Fabric クライアント Mod。軽量・高速なミニマップと全画面マップを提供します。

## 機能

### HUD ミニマップ
- 画面右下に常時表示（160×160 px）
- プレイヤーの向きを示す矢印（赤塗り・白縁取り）
- 水面透過（バシメトリー）: 水の下の地形を水色でブレンド、深さで暗化
- 連続シェーディング: N/NW/W 方向の高さ差から滑らかな明暗を計算
- バイオームティント: 草・葉・水の色をバイオームごとに適用

### 全画面マップ（`M` キー）
- Google Maps 式 Slippy Map タイル方式
- マウスカーソル位置を中心にズームイン/アウト
- スムーズズームアニメーション
- LOD（詳細度）: ズームレベルに応じて自動的に解像度を切り替え
  - zoom 5: 16 px/block（1 チャンク = 1 タイル）← 最大ズームイン
  - zoom 1: 1 px/block
  - zoom 0〜−3: 複数ブロックを平均化（最大 16 blocks/px）← 広域表示
- 右クリックドラッグでパン
- `R` キーでプレイヤー位置に再センタリング
- チラつき防止: チャンク更新中も古いタイルを表示し続け、新レンダリング完了後にシームレスに差し替え
- フォールバック表示: 高解像タイル未準備時に低解像タイルの一部を代替表示

### チャンクカラーキャッシュ
- 訪れたチャンクの色データをメモリに保持（アンロード後も維持）
- サーバー/ワールドごとにディスクへ永続化
  - シングルプレイ: `config/fastfastmap/cache/sp_<ワールド名>/chunks.dat`
  - マルチプレイ: `config/fastfastmap/cache/mp_<サーバーアドレス>/chunks.dat`
- 60 秒ごとに自動保存、ワールド離脱時にも保存
- 次回接続時にキャッシュを即座に読み込み → 未再訪エリアもマップに表示

## 操作方法

| 操作 | 動作 |
|------|------|
| `M` | 全画面マップを開く/閉じる |
| スクロールホイール | ズームイン/アウト（カーソル位置基準） |
| 右クリックドラッグ | マップをパン |
| `R` | プレイヤー位置に再センタリング |
| `ESC` / `M` | 全画面マップを閉じる |

## 技術仕様

### スレッドモデル

```
メインスレッド  ─── イベント受信 ──→ scanExecutor に投入
ワーカースレッド ─── チャンクスキャン + タイルレンダリング → colorCache / tilePixels
レンダースレッド ─── GPU アップロード / HUD 描画 / 全画面マップ描画
```

### タイルシステム

| zoom | px/block | blocks/tile | 用途 |
|------|----------|-------------|------|
| 5    | 16       | 16          | 最大ズームイン（1 チャンク = 1 タイル）|
| 4    | 8        | 32          | |
| 3    | 4        | 64          | |
| 2    | 2        | 128         | |
| 1    | 1        | 256         | デフォルト表示域 |
| 0    | 0.5      | 512         | |
| −1   | 0.25     | 1024        | |
| −2   | 0.125    | 2048        | |
| −3   | 0.0625   | 4096        | 広域表示 |

### キャッシュ設計

- `colorCache`: `チャンク座標(long)` → `ARGB int[256]`（全機能で共有、アンロードで削除しない）
- `tilePixels`: `TileCoord` → `int[]` ピクセル配列（RAM、任意スレッドから安全）
- `gpuTiles`: `TileCoord` → `NativeImageBackedTexture`（GPU、LRU 最大 128 タイル、レンダースレッドのみ）

### チラつき防止

```
チャンク更新
  └─ colorCache 更新
  └─ tilePixels 削除（RAM のみ）
  └─ ワーカーが新タイルをレンダリング
       └─ pendingGpuUpdate に通知
            └─ レンダースレッドが GPU テクスチャをシームレスに差し替え
               （古い GPU タイルは新タイル完成まで表示し続ける）
```

## ビルド

```bash
./gradlew build
```

出力: `build/libs/fastfastmap-<version>.jar`

## 動作環境

- Minecraft 1.21.11
- Fabric Loader 0.18.4+
- Fabric API 0.141.3+1.21.11

## 他Modとの互換性

| Mod | 互換性 | 備考 |
|-----|--------|------|
| **Bobby** | ✅ 推奨 | Bobby がキャッシュから復元したチャンクも CHUNK_LOAD イベント経由でスキャンされ、マップに表示される。Bobby（ブロックデータ）と fastfastmap（色データ）は独立したディスクキャッシュを持ち、相互補完する |
| **C2ME** | ✅ 互換 | チャンク生成並列化のみ。当 Mod の Mixin は `handleBlockUpdate` のみで衝突なし |
| **Lithium** | ✅ 互換 | サーバー側最適化。API 変更なし |
| **ModMenu** | ✅ 対応 | ModMenu のリストに表示される |
| **ScalableLux** | ✅ 互換 | ライティングエンジン置き換えのみ。Heightmap/BlockState は影響を受けない |
| **Sodium** | ✅ 互換 | チャンクレンダリングのみ置き換え。GUI 描画は標準 DrawContext を使用 |
